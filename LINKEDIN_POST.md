# LinkedIn Post Draft

Built and shipped my **Task 3: API-Based Weather App** using Python.

This project pulls **live weather data** from OpenWeather and presents it in an interactive desktop GUI.

### What I implemented
- City-based weather search
- Live temperature, weather condition, and humidity
- 5-day forecast view
- Error handling for invalid city/API/network issues
- Saved city history
- API key persistence so users do not need to re-enter the key every time

### Tech stack
- Python
- Tkinter (GUI)
- Requests
- OpenWeather API
